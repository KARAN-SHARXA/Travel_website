## About This Project

This is the **official production website** for **Kuldeep Tour & Travel**, a Himachal Pradesh–based travel business. It was developed as a freelance project to establish a strong online presence, rank on Google Search, and convert visitors into customers via WhatsApp booking.

> Currently ranking on Google Search for **"Kuldeep Tour and Travel"** with a verified 5.0 ⭐ rating on Google Maps.

The site handles everything a customer needs — browsing Himachal destinations, viewing tour packages, booking local rides, and reaching out instantly via WhatsApp — all without any backend or admin panel for maximum stability in production.

## Services

### 🚕 Local Rides
Available within a **100km radius of Kangra**. Customers fill a form with name, phone, pickup location, destination, date, and time.

### 🚉 Station & Airport Transfers
Fixed-route pickups and drops from railway stations and airports. Reliable, pre-scheduled transfers with WhatsApp confirmation.

### 📦 Fixed Tour Packages
Three curated packages with fixed routes and pricing:
- Amb Andaura → Devi Darshan Yatra
- Amb Andaura → Dharamshala Tour

## Key Features

- **Zero backend** — fully static, no downtime risk, no database dependency
- **Single source of truth** — all tour/destination data lives in one place, no duplication
- **WhatsApp-first booking** — customers reach the business in one tap
- **Mobile-first UI** — responsive across all devices (mobile, tablet, desktop)
- **SEO-optimized** — proper meta titles, descriptions, clean URLs, semantic HTML
- **OpenGraph ready** — rich previews when shared on WhatsApp and social media
- **Fast load times** — optimized images, Vite build, Vercel CDN
- **Search functionality** — filter tours by destination name

## Getting Started

### Prerequisites
- Node.js v18+
- npm or yarn

### Install & Run

```bash
# Clone the repo
git clone https://github.com/Lovelydehar3/kuldeep-tour-travel.git
cd kuldeep-tour-travel

# Install dependencies
npm install

# Start development server
npm run dev
# → http://localhost:5173
```

### Build for Production

```bash
npm run build
# Output in /dist — ready for Vercel
```

### Preview Production Build

```bash
npm run preview
```

## Deployment (Vercel)

The site auto-deploys from the `main` branch on every push.

**Manual deployment:**
1. Push to GitHub
2. Vercel picks it up automatically
3. Live within ~30 seconds

**First-time setup:**
1. Go to [vercel.com](https://vercel.com) → New Project
2. Import this GitHub repo
3. Framework: **Vite**
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy ✓

No environment variables required — the site is fully static.

---

## Design Decisions

**Why no backend?** This is a real business website, not a demo. A static site means zero server crashes, zero database downtime, and predictable behavior for real customers 24/7.

**Why WhatsApp booking?** The client's customers are already on WhatsApp. A phone call or form is an extra step. Click-to-chat removes all friction.

**Why TypeScript?** Prevents runtime bugs in production, especially important when all destination and package data is typed and reused across multiple pages.
